# Shu point plates (SVG)

Standalone SVG versions of the Shu Atlas plates, prepared for reuse (for example on Wikimedia Commons). Each plate shows one channel with only its five Shu points.

| File | Source of the drawing | License |
|---|---|---|
| `Shu_points_of_lung_channel.svg` | "Points of lung channel" by Dimitrius ([Commons](https://commons.wikimedia.org/wiki/File:Points_of_lung_channel.svg)), relabelled P → LU, non-Shu points removed | CC BY-SA 3.0 |
| `Shu_points_of_heart_channel.svg`, `…_pericardium_…` | Same Dimitrius arm drawing, palm side; channel and points redrawn | CC BY-SA 3.0 |
| `Shu_points_of_small_intestine_channel.svg`, `…_triple_burner_…` | Same drawing mirrored to the back of the arm, back of the hand redrawn; channel and points redrawn | CC BY-SA 3.0 |

Point locations follow standard textbook descriptions (see each channel page in the app). Modifications and new drawing: Abdul Rahman P Z, 2026.

Not included: the Large Intestine plate and the six leg plates, which are traced from images whose licence is not yet confirmed.
